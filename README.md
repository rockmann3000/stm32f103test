Тестовая программа для stm32f103c8t6.  
Запуск таймера реального времени, инициализация счётчика чч:мм:сс и отправка показаний в виде ASCII строки в USART
Раз в 0,2с.  
Код написан с использованием библиотеки CMSIS.  
Для счёта времени использовалось прерывание таймера RTC по секундному переполнению.  
Для передачи сформированной строки использовался контроллер DMA в связке с USART1.  
Для инициализации передачи использовался таймер TIM4 в режиме сброса по сравнению на время 0.2с,
который запускал одиночную транзакцию DMA.  
Так же реализован функционал таймера задержки delay_ms() на базе системного таймера systick.  
Реализован функционал подстройки таймингов systick в зависимости от источника тактирования (базовый кварц 8МГц на
плате bluepill + PLL).
